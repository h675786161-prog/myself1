# 酒馆美化拼拼乐

一个用于 SillyTavern 主题设计的拖拽式美化拼装工具。

## 功能

拖拽组件、位置尺寸调整、旋转、透明度、圆角、层级、镜像、锁定、撤销重做、3-2-1 主题规则、25% 缩略图检查、主题预设、JSON/CSS/PNG 导出和浏览器本地存档。
